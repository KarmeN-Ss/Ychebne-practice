Проектная практика

Проект посвящён разработке настольного приложения на C# для анализа содержимого дисков и каталогов.

Аннотация проекта

Программа предназначена для рекурсивного анализа файловой системы, определения размеров файлов и каталогов и поиска объектов, занимающих значительный объём дискового пространства.

Проект позволяет удобнее анализировать структуру диска и находить крупные файлы и папки.

Основные возможности

  • Рекурсивное сканирование каталогов
  • Определение размеров файлов и папок
  • Сортировка объектов по размеру
  • Поиск крупных файлов
  • Отображение результатов анализа
