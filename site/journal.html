Пост 1. Начало работы

Создан репозиторий на основе шаблона, изучена структура и заполнены основные данные.

Пост 2. Документация и сайт

Изучен Markdown, подготовлена документация, создана структура статического сайта на HTML и CSS.

Пост 3. Разработка курсового проекта

Создано WPF-приложение DiskAnalyzer для анализа дискового пространства и работы с файловой системой.

Пост 4. Работа с большим объёмом данных

Проведено тестирование на системном диске. Для обработки сотен тысяч объектов добавлен постраничный вывод результатов и оптимизировано обновление интерфейса.

Пост 5. Завершение основных функций

Добавлены фильтрация по типу, сортировка по пути, режим нерекурсивного анализа, список недоступных объектов, открытие файлов через Проводник и вкладка визуализации.
