# Отчёты

В этом каталоге размещаются итоговые материалы проектной практики.

## Планируемые файлы

- Отчёт.docx — итоговый отчёт по практике в формате DOCX.
- Отчёт.pdf — PDF-версия итогового отчёта.
- practice_report_template.docx — исходный шаблон отчёта.

После завершения подготовки итогового отчёта DOCX и PDF будут переданы в СДО.
