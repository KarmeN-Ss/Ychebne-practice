# Документация по проектной практике

## Журнал выполнения

### 1. Настройка репозитория

Создан форк шаблонного репозитория, изучена его структура, заполнен основной файл README.md личными данными.

### 2. Изучение Git

Изучены основные операции работы с Git: создание веток, фиксация изменений с помощью коммитов, синхронизация репозитория и работа с удалённым репозиторием.

### 3. Изучение Markdown

Изучен базовый синтаксис Markdown: заголовки, списки, ссылки, выделение текста и блоки кода. Подготовлена документация по выполнению проектной практики.

### 4. Создание статического сайта

Создаётся статический веб-сайт проекта с использованием HTML и CSS. На сайте будут представлены описание проекта, участники, журнал работы и полезные ресурсы.

### 5. Взаимодействие с организацией-партнёром

На данном этапе планируется организация взаимодействия с организацией-партнёром в соответствии с заданием практики.

### 6. Итоговый отчёт

По завершении основных этапов практики будет подготовлен итоговый отчёт в форматах DOCX и PDF.
