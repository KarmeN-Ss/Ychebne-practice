# Документация по проектной практике

## Журнал выполнения

### 1. Настройка репозитория

Создан форк предоставленного шаблонного репозитория. Изучена его структура и заполнен основной файл README.md личными данными и информацией о проекте.

### 2. Работа с Git

Изучены основные операции системы контроля версий Git: создание веток, фиксация изменений с помощью коммитов, синхронизация репозитория, клонирование и отправка изменений в удалённый репозиторий.

Работа над проектом ведётся поэтапно с осмысленными сообщениями коммитов.

### 3. Документация в Markdown

Изучен базовый синтаксис Markdown: заголовки, списки, ссылки, выделение текста и блоки кода. Документация практики и описание проекта ведутся в формате Markdown.

### 4. Статический веб-сайт

Создан статический веб-сайт проекта с использованием HTML и CSS.

Сайт содержит главную страницу с аннотацией проекта, страницы «О проекте», «Участники», «Журнал» и «Ресурсы», графическую схему и материалы партнёрского взаимодействия. Публикация выполняется через GitHub Pages с помощью GitHub Actions из каталога `site/`.

### 5. Взаимодействие с организацией-партнёром

Выполнено взаимодействие в рамках профессионального интенсива и тренинга-игры «ТехноСтарт» (тренинги предпринимательских компетенций), проведённого в рамках федерального проекта «Платформа университетского технологического предпринимательства». Оператор тренингов — МФТИ.

В ходе мероприятия были изучены основы проектирования бизнес-модели технологического проекта, структура Business Model Canvas, подходы к определению целевой аудитории и ценностного предложения, разработке MVP, оценке рынка и распределению командных ролей.

Подтверждением участия является сертификат. Отчёт о взаимодействии подготовлен в формате Markdown и добавлен в репозиторий в файле `partner_report.md`.

### 6. Вариативная часть — курсовой проект

В качестве вариативной части выполнена разработка настольного приложения на C# и WPF (.NET Framework) для анализа дискового пространства.

Основные реализованные функции:
- выбор каталога;
- рекурсивное и нерекурсивное сканирование;
- подсчёт размеров файлов и папок;
- фильтрация по типу объекта;
- сортировка по размеру, имени, типу и пути;
- поиск по имени и полному пути;
- постраничное отображение большого количества результатов;
- отображение статистики сканирования;
- отмена длительного сканирования;
- фиксация недоступных объектов;
- открытие файла в Проводнике с его выделением;
- визуализация крупнейших объектов каталога.

Исходный код проекта размещается в каталоге `src/`. Подробное описание находится в файле `docs/course_project.md`.

### 7. Итоговый отчёт

После завершения оформления документации будет подготовлен итоговый отчёт по проектной практике в форматах DOCX и PDF. Файлы будут размещены в каталоге `reports/` и переданы в СДО в соответствии с требованиями практики.
