# Курсовой проект: DiskAnalyzer

## Назначение

DiskAnalyzer — настольное приложение на C# и WPF (.NET Framework), предназначенное для анализа файловой системы и поиска объектов, занимающих значительный объём дискового пространства.

## Основные задачи

1. Рекурсивно обходить выбранный каталог.
2. Определять размеры файлов и каталогов.
3. Показывать результаты в табличной форме.
4. Предоставлять поиск и сортировку.
5. Позволять ограничить область анализа непосредственным содержимым выбранной папки.
6. Обрабатывать недоступные объекты файловой системы.
7. Поддерживать длительные операции без блокировки пользовательского интерфейса.

## Реализованные возможности

### Сканирование

Пользователь выбирает каталог и запускает анализ. В рекурсивном режиме программа обходит вложенные каталоги и суммирует размеры файлов.

### Нерекурсивный режим

При отключении рекурсивного сканирования программа рассматривает только файлы и непосредственные подпапки выбранного каталога. Внутрь подпапок она не заходит.

### Поиск и фильтрация

Поиск выполняется по имени объекта и его полному пути. Фильтр позволяет оставить все объекты, только файлы или только папки.

### Сортировка

Результаты сортируются по размеру, типу, имени или полному пути.

### Постраничный вывод

Вместо одновременной отрисовки всего набора данных интерфейс показывает результаты страницами. Это позволяет работать с большими наборами объектов файловой системы.

### Недоступные объекты

Пути объектов, которые не удалось прочитать из-за ограничений доступа или ошибок файловой системы, выводятся на отдельной вкладке.

### Работа с Проводником

Для файла приложение открывает расположение объекта и выделяет сам файл. Для папки открывается соответствующий каталог.

### Визуализация

Отдельная вкладка показывает крупнейшие непосредственные объекты выбранного каталога и их долю в общем размере.

## Тестирование

Один из тестовых сценариев выполнялся на системном диске. Было обработано более 575 тысяч объектов файловой системы.

Испытание показало, что отображение всего набора в таблице одновременно создаёт дополнительную нагрузку на интерфейс. Поэтому итоговая версия использует постраничный вывод и ограниченное количество одновременно отображаемых элементов.
