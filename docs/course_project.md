# Курсовой проект: DiskAnalyzer

## Назначение

DiskAnalyzer — настольное приложение на C# и WPF (.NET Framework), предназначенное для анализа файловой системы и поиска объектов, занимающих значительный объём дискового пространства.

## Реализованные функции

- рекурсивное и нерекурсивное сканирование;
- расчёт размеров файлов и папок;
- поиск по имени и полному пути;
- фильтрация по типу объекта;
- сортировка по размеру, имени, типу и пути;
- постраничный вывод больших результатов;
- отмена длительного сканирования;
- фиксация недоступных объектов;
- открытие файла с выделением в Проводнике;
- визуализация крупнейших непосредственных объектов выбранного каталога.

## Архитектура

Приложение разделено на графический интерфейс, модель объекта файловой системы и сервис сканирования. Длительная операция выполняется вне UI-потока, а результаты выводятся порциями.

## Тестирование

На системном диске выполнялось тестовое сканирование с сотнями тысяч файлов и папок. Испытание показало необходимость постраничного отображения и ограничения обновлений интерфейса.

## Технологии

C#, WPF, .NET Framework, System.IO, Task.Run, CancellationToken и DataGrid.
