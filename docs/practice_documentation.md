# Документация по проектной практике

## Журнал выполнения

### 1. Настройка репозитория

Создан форк предоставленного шаблонного репозитория. Изучена его структура и заполнен основной файл README.md личными данными и информацией о проекте.

### 2. Работа с Git

Изучены основные операции системы контроля версий Git: создание веток, фиксация изменений с помощью коммитов, синхронизация репозитория, клонирование и отправка изменений в удалённый репозиторий.

Работа над проектом ведётся поэтапно с осмысленными сообщениями коммитов.

### 3. Документация в Markdown

Изучен базовый синтаксис Markdown: заголовки, списки, ссылки, выделение текста и блоки кода. В репозитории ведётся документация и журнал выполнения проектной практики.

### 4. Статический веб-сайт

Создаётся статический веб-сайт проекта с использованием HTML и CSS.

Сайт содержит главную страницу с аннотацией проекта, страницы «О проекте», «Участники», «Журнал» и «Ресурсы». В материалы сайта добавляются графические материалы и материалы демонстрации проекта.

### 5. Взаимодействие с организацией-партнёром

Выполнено взаимодействие в рамках профессионального интенсива и тренинга-игры «ТехноСтарт» (тренинги предпринимательских компетенций), проведённого в рамках федерального проекта «Платформа университетского технологического предпринимательства». Оператор тренингов — МФТИ.

В ходе мероприятия были изучены основы проектирования бизнес-модели технологического проекта, структура Business Model Canvas, подходы к определению целевой аудитории и ценностного предложения, разработке MVP, оценке рынка и распределению командных ролей.

Подтверждением участия является сертификат. Отчёт о взаимодействии подготовлен в формате Markdown и добавлен в репозиторий в файле `partner_report.md`.

Полученные знания связаны с проектом через задачи определения целевой аудитории, формулирования ценности продукта и планирования минимально жизнеспособной версии решения.

### 6. Курсовой проект

В качестве основы вариативной части практики выполняется разработка настольного приложения на C# и WPF (.NET Framework) для анализа дискового пространства.

Основные функции проекта:
- выбор каталога;
- рекурсивное сканирование файловой системы;
- определение размеров файлов и папок;
- сортировка результатов;
- поиск по имени и пути;
- отображение статистики;
- отмена длительного сканирования;
- обработка недоступных объектов файловой системы.

Исходный код размещается в каталоге `src/DiskAnalyzer/` и связан с темой курсового проекта.

### 7. Итоговый отчёт

После завершения основных этапов будет подготовлен итоговый отчёт по проектной практике в форматах DOCX и PDF. Файлы будут размещены в каталоге `reports/` и переданы в СДО в соответствии с требованиями практики.
