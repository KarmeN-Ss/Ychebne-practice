## Проект по «Проектной деятельности»

**Анализатор дискового пространства** — настольное приложение на C# и WPF для рекурсивного анализа файловой системы, определения размеров файлов и папок, поиска крупных объектов и отображения результатов анализа.

## Вариативная часть задания

В качестве практической основы вариативной части выполняется собственный курсовой проект — разработка настольного приложения на C# и WPF (.NET Framework) для анализа дискового пространства.

Результаты разработки, документация и материалы проекта интегрируются в репозиторий и статический сайт.
