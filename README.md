## Проект

**DiskAnalyzer — анализатор дискового пространства** — настольное приложение на C# и WPF (.NET Framework), предназначенное для анализа файловой системы, поиска крупных файлов и каталогов и удобного просмотра результатов сканирования.

## Вариативная часть

В качестве вариативной части выполнен курсовой проект по разработке DiskAnalyzer.

В приложение реализованы:
- рекурсивное и нерекурсивное сканирование;
- расчёт размеров файлов и папок;
- поиск по имени и полному пути;
- фильтрация по типу объекта;
- сортировка по размеру, типу, имени и пути;
- постраничное отображение больших объёмов результатов;
- отмена длительного сканирования;
- отображение недоступных объектов;
- открытие файлов и папок в Проводнике;
- визуализация крупнейших объектов выбранного каталога.

Исходный код проекта находится в [src](src/).
